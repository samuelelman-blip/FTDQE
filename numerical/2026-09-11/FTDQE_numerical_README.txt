FTDQE numerical release, numerical-2026-09-11

Download all numbered part ZIPs and extract them into the same directory. They are ordinary ZIP files with disjoint contents under the common FTDQE_numerical_2026-09-11 folder; no binary concatenation is needed.

Together they contain exactly the same 869 entries (868 manifest-listed files plus MANIFEST.json) as the original combined archive. No numerical file or manuscript was changed when splitting. Run python verify_manifest.py from the extracted common folder to check all file identities. See README.md and EXHIBIT_INDEX.json there for numerical validation and reproduction.

FTDQE_numerical_parts_SHA256SUMS.txt identifies the numbered ZIP downloads. The earlier FTDQE_release_SHA256SUMS.txt identifies the PDF, original source ZIP and combined numerical archive; that combined archive is now distributed through these smaller ordinary ZIPs.

FTDQE_flat_corrected.zip is the flattened manuscript source, with main.tex at its root. It has its own FTDQE_flat_corrected_SHA256.txt.
